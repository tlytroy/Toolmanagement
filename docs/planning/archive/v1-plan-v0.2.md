## 0. 一句话目标（修订）

**拍一张 A4 纸上的工具照片 → 得到物理尺寸正确、装得进/拿得出/打得动的凹槽 → 导出 STL 直接打印。**

v0.1 只写了"物理尺寸正确"。红队指出：**尺寸正确只是第一关，后面还有四关**——第三维（厚度）、配合（间隙）、可打印性（壁厚/分块/用料）、取出人因（手槽）。这四关在 v0.1 里全部没有参数、没有里程碑、没有验收。

**v0.2 的核心变化：把"能不能真的用"抬到与"尺寸准不准"同级。**

## 3. 设计决策（v0.2 修订版）

### D1 像素→毫米标定（v0.1 方案被红队判定为"污染单位换算"，已改）

**v0.1 的错**：`px_per_mm = clamp(纸长边像素/297, 6, 12)`。若真实值 5.09 被 clamp 到 6，200mm 扳手的槽会算成 236mm，STL 水密、无报错、直接打废。且若 `warp_paper` 输出"固定物理分辨率"，则 `纸长边/297` **恒等于**该常数，clamp 是死代码；若走自适应，饱和后必须显式重采样才成立。

**v0.2 方案**：

```
ppmm_src = 源图中 A4 长边像素均值 / 297
若 ppmm_src < 6.0  → 返回错误 "照片分辨率不足，请靠近拍摄"，不上采样
若 ppmm_src > 12.0 → ppmm = 12.0（下采样，多余分辨率只增点数）
否则              → ppmm = ppmm_src
warp 输出尺寸 = round(210*ppmm) × round(297*ppmm)      # 强制 √2，消除 x/y 各向异性
响应返回 { px_per_mm, warp_width, warp_height }
```

**为什么不上采样**：上采样不创造信息，只会让"看起来能算"变成"算得不准"，且比直接报错更危险。

**为什么强制 √2**：A4 是 210:297 = 1:1.41421。若输出取整到 `int(w_edge)`/`int(w_edge/1.414)`，x/y 实际 ppmm 会差 0.1%~0.3%，200mm 上就是 0.5mm，白送误差。

**下游全链路**：
- `sam_tool_contour.py` 的像素常数（`ck = max(5,int(min(h,w)*0.012))|1`、边框 2%、开运算 3×3）全部改 `k_mm × ppmm`，并设下限 3px
- `_extrude_tool_slot` 用 `poly_mm = poly_px / ppmm` 并保留**绝对位置**（相对底板原点），不再居中
- 前端类型补 `px_per_mm`

**副作用要认**：`ck` 在 8ppmm 下从 28px 掉到 16px，识别质量会变。所以 `tests/` 5 张 jpg 的**改前/改后回归对比是前置条件，不是缓解措施**。

### D2 多工具路径（不变，B1）

**一张照片一把工具 + 前端工具列表累积。**
理由：两把工具贴在一起时 `RETR_EXTERNAL` 只有一个连通块；当前"最大连通块 + bbox 外扩 8% 合并"（`sam_tool_contour.py:198-208`）恰恰对多工具是反作用。自动拆分在重叠/贴边/阴影下无解，等于上实例分割，代价远超收益。

**新增（响应 R13 超 A4）**：单把工具超出 A4 → 走 R12 手动建槽（填长/宽/端部形状），**不做照片拼接**。拼接的对齐误差和遮挡远比手工填几个数麻烦。

---

### D3 排版（v0.1 的 AABB + MaxRects 被判定"浪费灾难级"，已改）

**v0.1 的错**：200×15mm 螺丝刀转 45° → AABB 变 152×152（7.7× 浪费），MaxRects 会判"放不下"。且经典 MaxRects 只支持 90° 旋转。

**v0.2 方案**：
- **碰撞与占位用 `shapely.minimum_rotated_rectangle`**（O(n)），不用轴对齐 AABB
- **占位多边形 = 工具槽 ∪ 全部手槽 ∪ `fit_clearance`** 的并集 —— 红队 P0-1 的关键：v0.1 只排工具 AABB，会系统性地把手槽埋进相邻槽壁
- **碰撞检测**：`shapely.STRtree` 预筛 → 粗筛用凸包 → 松手时全精度 `distance()`
- **分区**：拖拽中（>30fps）用凸包 + 简化轮廓；松手后跑全精度校验
- **不做完整 MaxRects**。自动排版只需"初始不重叠"：按占地降序 + `minimum_rotated_rectangle` 的 shelf 式贪心即可
- **增量插入**：已放置工具默认锁定，新工具只在剩余空隙找位；全量重排要二次确认；手工旋转角持久化
- **1mm 吸附是"共面制造机"**（恰好相切比重叠难处理），吸附后强制重叠 0.05mm

---

### D4 几何内核（v0.1 的 2.5D loft 被判定"方向对、实现不能"）

**结论保留 C1（trimesh + manifold3d + 2.5D loft），不转 cadquery。** 理由不变：真实出口是 STL；OCCT 对上千点凹轮廓的变半径 fillet 确实脆。**但要补一句**：红队指出"OCCT 必崩"是过度概括——对**棱柱**的两条水平边环做定距 chamfer 恰是 OCCT 最稳的操作。所以：**C1 为主路径，OCCT 作为可选的 golden reference 校验**（同一份 profile 喂两后端对照），不进主链。

#### D4.1 扔掉"沿周长均匀重采样"，改 miter 法向偏置

v0.1 自己承认"buffer 改变顶点数，不能按索引连线，必须均匀重采样"。红队判定这个补丁**比原问题更糟**，且**静默失败**：

| 失效机理 | 具体场景 |
|---|---|
| `buffer(-t)` 是集合运算，细颈断成 MultiPolygon、细突起整条消失 | 游标卡尺爪尖 1.5mm + `c_bot=2` → 底层轮廓消失，取主环后重采样会把爪尖位置**拉直跨过**，而上层有爪尖 → **槽口被封死** |
| 均匀弧长按总周长比例配对，而周长变化非均匀 | 圆角化使周长增、凹口填平使周长减 → 下游所有点整体漂移 → 侧壁扭转、45° 面变 30~60° |
| 凹角 offset 解距原顶点 `d/sin(θ/2)`，θ→0 时无界 | 尖嘴钳内凹、扳手开口根部会喷出 15mm 尖刺，重采样直接抹掉 |
| 讽刺：buffer 的 round join 每凸角 +16 点且每层数量不同 | **2D 合法性 ≠ 3D 对应性**。buffer 越稳，对应关系越差 |

**v0.2 算法**：

```
以"基环顶点索引"为唯一真值：
  对每个顶点 i，取相邻两边的单位法向 n1,n2
  miter = (n1+n2) / |n1+n2|，按 1/cos(θ/2) 归一化，即 1/(n1·miter)
  P_i(t) = P_i + t · miter_i          ← 层间顶点数恒为 N，对应关系由构造保证
凹角处逐顶点变宽度降级：
  t_max_i 由 medial axis（shapely 先验：点到边界距离的局部极大）给出
  t_i = min(t_request, t_max_i)       ← "尖角处倒角变窄"，而不是"特征消失"
```

这一步把方案性质从"脆"变成"退化可控"：顶点数恒定、每条边生成精确平面、凹角自动降级为更窄的倒角。

#### D4.2 拆开四种符号不同的倒角（v0.1 用同一个 `buffer(-t)` 表达，是符号错误）

v0.1 的伪代码给 `buffer(-t)`，但 M1 参数名写"槽口**外扩**"。**符号反了**：用在减体上得到的是内唇边（retention lip），用户手感"进不去"，模型完全水密。

| 倒角位置 | 作用对象 | 方向 | 参数 |
|---|---|---|---|
| 底板外缘·顶 | 基底 | 内缩 | `top_chamfer_mm` + `top_chamfer_angle` |
| 底板外缘·底 | 基底 | 内缩 | `bottom_chamfer_mm` + `bottom_chamfer_angle` |
| **槽口** | **减体** | **外涨** | `slot_chamfer_mm`(默认 1.5) + `slot_chamfer_angle`(默认 45) |
| 槽底 | 减体 | 内缩（圆角） | `slot_floor_fillet_mm` |
| 内孔 | 减体 | **外胀**（向外廓相反的方向） | 独立环，独立索引 |

**参数一律 `(width_mm, angle_deg)`，不用单标量**——单标量把角度锁死 45°，而 30° 更利于打印。

**剖面升级为曲线表** `[(z_j, t_j)]`：v0.1 的三段线性 `t(z)` 出的是**圆锥面不是圆角**。真圆角需 `t(z) = r − sqrt(r² − (r−z)²)`，8~16 层。

#### D4.3 处理"轮廓缩没了"

v0.1 全文没有 empty / MultiPolygon / interiors 的处理。**必须**：
- 二分求 `max d s.t. Polygon 有效 ∧ 洞数不变 ∧ area ∈ (0, P.area)`
- 约束 `c_top + c_bot ≤ H − min_floor`
- **clamp 结果必须回传 UI 并标红受限顶点** —— 悄悄把 5mm 给成 1.8mm 等于骗人

#### D4.4 抽稀是必须项，不是优化项

红队估算：8ppmm 下 200mm 工具周长 4800px → 3000~5000 点；12ppmm 达 8~10k；乘 round join 膨胀 → 每工具 20 万点、5 工具 100 万点。

**两级数据，不混用**：
- **显示/编辑**：全分辨率
- **建模**：Douglas–Peucker 到 0.1~0.15mm（300~600 点），布尔开销降一个数量级

必须**删共线点**，否则 earcut 产生 sliver，`is_watertight` 仍会通过。

#### D4.5 布尔守卫（v0.1 完全没有）

| 守卫 | 判据 | 失败动作 |
|---|---|---|
| 槽壁最小厚度 | `pocket.buffer(wall_min).within(board.buffer(-wall_min))`，`wall_min = 1.2mm` | 阻断导出 + 高亮 |
| 槽是否穿透侧壁 | 同上 | 阻断 |
| 是否产生浮岛 | `board − pockets` 跑连通域，>1 个连通块即报警 | 阻断 |
| 槽体是否真的挖空 | `tool_solid.difference(pocket_solid).volume ≈ 0` | 阻断（这是抓"倒角方向错"的唯一可靠判据） |
| 共面退化 | `embed_depth = H` 时改 `H − 0.2`，且减体向上伸到 `H + 10` | 自动 |
| 槽底剩余厚度 | `embed_depth ≤ H − 1.2` | 阻断 |
| 自动装满的板 | `bbox + 边距` 只保证"装得下"，**不保证壁厚**（300mm 撬棍配 300mm 板 → 槽切穿侧壁） | 跑上面的壁厚守卫 |

### D5 轮廓手动调整（v0.1 只做拖顶点+删段，被判"修不了最常见失败"）

### D6 手槽：**形态要换**（v0.1 的 YZ 半胶囊横向孔道不成立）

红队指出 v0.1 三条约束彼此不自洽：长轴端点**不在轮廓上**（L 形内六角、钩形扳手）；"外法线"在凹顶点有歧义；水平孔道**打不通到板外缘**（100mm 槽居中在 300mm 板上，侧向孔 30mm 够不到）→ 成盲隧道 + FDM 桥接下垂。

**v0.2 方案：手槽 = 工具槽轮廓上的 2D 局部外凸（scoop），与工具槽同深度。**

```
pocket_final = pocket(buffer=fit_clearance) ∪ scoops
scoop = 半圆/胶囊，圆心落在 pocket 边界上，向外凸出 depth_mm
```

**为什么这个形态对**：
1. **天生正确**：同一深度、同一个 2D 布尔、同一套 miter 偏置，**没有第三个坐标系**
2. **不会成盲隧道**：它不是一个独立的 3D 孔道，而是槽口局部的加宽
3. **人因可量化**：凸出的弦长 = 手指进入宽度，凸出深度 = 手指下探深度
4. **拿取逻辑成立**：手指从上方伸进 scoop，捏住工具边缘

**人因下限（红队给的数，写进参数约束）**：
| 参数 | 下限 | 说明 |
|---|---|---|
| 弦长（沿轮廓） | ≥ 20mm（重工具 ≥ 35mm） | 手指进入宽度 |
| 凸出深度 | ≥ 12mm 且 ≥ `embed_depth + 5mm` | 手指下探 |
| 口部坡口 | ≥ 3mm @ 45° | 滑入；**v0.1 默认 0.5mm 对滑入毫无作用** |
| 顶面净空 | ≥ 50mm | 板顶到抽屉/工具箱盖 |

**自动放置（替代 PCA 长轴端点）**：
- 取 `P.boundary` 与长轴方向的**交点**，用所在**边**的法线（不用顶点法线，扇形有歧义）
- 沿长轴按 `perimeter/3` 取候选点，按"距板边距离 + 与相邻槽距离 + 是否靠近重心"打分，取 top-2
- 约束：`scoop_solid ∩ tool_solid = ∅` 且留 ≥1.5mm 搭接（否则 1mm 塞尺条会掉下去）；**不能用"2D 投影重叠 ≤30%"** —— 手指在任何 z 都不能与工具实体相交，2D 丢掉了 z

**稀有形态保底**：`embed_depth < 12mm`（薄片工具）时，手指下不去，改在槽底做 +3mm 浅坑（P2，v1 可只给提示不实现）。

**布局联动**：红队 P0-1 的硬要求 —— 每个工具必须存在一条从槽口到板边的无遮挡手指通道，排版把 scoop 计入占位，导出前校验。

## 4. 新增的设计：R11 厚度、R14 间隙、R15 可打印性、R17 精度

### D8 厚度 / 嵌入深度从哪来（R11）

**问题**：单张俯拍只有 2D 轮廓。用户填 `embed_depth` 时不知道该填多少（量手柄 12mm，实际钳头 22mm）。

**方案**：
- **按工具类型的默认档**：薄片 6 / 常规 12 / 厚件 25 / 通孔全高
- **3D 预览里拖"嵌入深度"滑块**，直接看工具半埋效果（视觉比数字可靠）
- **不强制**用户量厚度；但若 `embed_depth < 建议值`，提示"工具会晃动"
- 可选：让用户把工具侧放在纸旁同框再拍一张做厚度估计（P2，v1 不做）

### D9 配合间隙与试切件（R14）

- `fit_clearance_mm`（默认 **0.4**，范围 0~1.5）：槽整体外扩
- `global_fit_bias_mm`（−0.5~+1.5）：一键应用到全部槽，**打印后微调用的救命参数**
- 两套预设：**硬质**（PLA/PETG，0.4 间隙，含收缩补偿）、**柔性**（TPU/泡沫，0 间隙）
- **试切校准件**：40×40×10mm 带同一个槽的小方块，20 分钟打完，先验证松紧再打整板
- 打印收缩：PLA ≈ 0.2~0.4%，200mm 件 = 0.4~0.8mm。**v0.1 的 DoD 没有这一项，光这一项就吃掉 1mm 预算**
- **公差非对称**：+1.5 / −0.3（宁松勿紧）

### D10 可打印性（R15）

| 项 | 默认 | 说明 |
|---|---|---|
| `wall_thickness_mm` | 2.4 | 槽与槽、槽与板边之间 |
| `floor_thickness_mm` | 1.6 | 槽底剩余 |
| `base_hollow` | true | 底部挖空留 6mm 网格肋，而不是实心块减槽 |
| 分块 | 可填床尺寸 | ① Gridfinity 42mm 天然分块 ② 自由板燕尾拼缝 0.2mm 间隙 |
| 用料/工时 | 导出前显示 | 300×400×25 实心块 = 1.4kg / 31 小时，不提示用户会放弃 |
| 几何自检 | 自动 | 槽间距 <1.2 / 槽壁到板边 <2.0 / 槽底 <1.2 → 阻断导出并高亮 |

### D11 精度承诺（R17）

**v0.1 写"STL 槽长误差 ≤1mm"，物理上兑现不了。** 主导误差不在 CV：

| 误差源 | 量级（200mm 工具） | v0.1 是否提及 |
|---|---|---|
| 四角检测（±15px @ 3000px） | ~1.0mm | 未提 |
| **视差**（20mm 厚 + 20° 偏角，`Δ = t·tanθ`） | **7mm** | **未提** |
| 镜头径向畸变（手机广角 1~3%） | 2~6mm | 未提 |
| 分割（阴影/边缘） | 1~3mm | 未提 |
| **FDM 收缩**（0.2~0.4%） | 0.4~0.8mm | 未提 |
| 切层量化 | 0.1mm | — |
| A4 打印缩放（"适合页面"） | 6~10mm | 提到了，但只在打印标记纸时存在 |

**v0.2 改为条件承诺**：

| 档 | 条件 | 承诺 |
|---|---|---|
| S0 | 厚件 t ≤ 10mm，俯拍与纸面夹角 ≤10°，纸平整，ppmm ∈ [6,12]，已开收缩补偿 | **±1.5mm** |
| S1 | 典型：t ≤ 25mm，夹角 ≤20° | **±2% 或 ±3mm** |
| S2 | 超出 S1 | 明确告知"请用厚度补偿或手动建槽"，**不承诺** |

**配套**：
- **视差补偿**：EXIF 焦距 + A4 像素宽反算距离 `d ≈ f_px·210/w_px`，轮廓按 `(d−t)/d` 向主点径向收缩。EXIF 缺失时用保守 `d=300mm` 并提示
- **拍摄指引三图**：正上方俯拍 / 纸四边留 20mm 白边 / 工具按**收纳状态**摆放（钳口闭合、卡尺归零、折叠工具展开到常用角度 —— 否则拍的 180mm 卡尺做成槽，收进去左右各晃 15mm）
- **上传时阻断**：明显斜拍、纸出画、过曝
- **DoD 改为矩阵**：3 类厚度 × 3 次独立拍摄 × 2 种光照，记误差分布，**p95 ≤ 承诺值**，且不只量切片网格还要**打印后卡尺量**
